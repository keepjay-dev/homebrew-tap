# Keepjay Homebrew tap

[Keepjay](https://github.com/keepjay-dev/keepjay) is local-first spaced repetition for
developers: flashcards in your code comments, reviewed while your tests run.

```sh
brew install keepjay-dev/tap/keepjay
```

This installs `keepjay` and its short alias `kj`, for macOS (Apple silicon and Intel) and
Linux (x86-64). `brew upgrade keepjay` updates it. Then see
[Getting started](https://github.com/keepjay-dev/keepjay/blob/main/docs/guide/getting-started.md).

If another formula already provides a `kj` command, Homebrew stops and names it rather than
replacing it.

## How the formula is updated

`Formula/keepjay.rb` is generated by `scripts/update-formula.sh` from a Keepjay release and
its published `SHA256SUMS.txt`. The **Update formula** workflow runs every 6 hours: when
there's a newer release, it installs and tests the new formula on macOS and Linux, then
commits it. Run it by hand from the Actions tab to update straight away, or to package a
particular release.

Issues with Keepjay itself go to
[keepjay-dev/keepjay](https://github.com/keepjay-dev/keepjay/issues).
